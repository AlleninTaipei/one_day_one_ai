# 一天一AI — 文章摘要索引

數位時代「[一天一AI](https://www.bnext.com.tw/tags/%E4%B8%80%E5%A4%A9%E4%B8%80AI)」專欄的文章索引，以互動式 HTML 捲動式單頁文件呈現。

---

## 專案內容

本專案自動追蹤數位時代「一天一AI」專欄，將文章整理成兩個同步格式：

| 檔案 | 用途 |
|------|------|
| `onedayoneai.md` | 純文字索引，含更新紀錄(最近 2 次)與主題分類 |
| `onedayoneai.html` | 互動式捲動頁面，支援深色／淺色模式切換 |

---

## 互動式頁面功能

開啟 `onedayoneai.html` 即可使用：

- **捲動瀏覽**：由上至下依序為更新摘要、更新紀錄、主題分類
- **深色 / 淺色模式**：右上角切換按鈕
- **更新紀錄**：保留最近 2 次更新(本次與前次)新增的文章，含發布時間與分類
- **新文章標示**：本次新增的文章以銅橘色左邊框標示
- **分類連結**：主題分類區塊是唯一的完整文章清單，可直接點擊跳至原文

## 更新方式

本專案搭配 **Claude Code** 自動化更新。在 Claude Code 中輸入「請更新」，即會自動：

1. 從第 1 頁起抓取標籤頁所有分頁, 直到無內容為止
2. 與主題分類清單比對, 識別新增文章
3. 同步更新 MD 與 HTML 兩個檔案, 並輪替更新紀錄(只保留本次與前次)

## 改版紀錄

### 2026-09-18 移除頁次表格, 改為更新紀錄

- 原因: 網站標籤頁已從 3 頁增加為 6 頁, 且頁次會隨新文章發布位移, 本地的「第一頁至第三頁」表格無法對應網站實際頁碼, 內容也與主題分類重複
- 移除第一頁至第三頁的文章表格
- 新增「更新紀錄」區塊, 只保留最近 2 次更新, 表格欄位為標題, 發布時間, 分類, 連結
- 主題分類改為唯一的完整文章清單: MD 補上連結並改用網站完整標題, 合併 MD 與 HTML 原本不一致的分類歸屬, 補齊 1 篇未分類文章, 共 154 篇皆已歸類
- 抓取範圍由固定 3 頁改為抓到無內容為止
- 頁首篇數改為「共計 N 篇文章」
